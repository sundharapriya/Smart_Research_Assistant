# Smart_Research_Assistant

An AI-powered research assistant that uses **Generative AI and NLP** to summarize articles and answer questions based on their content.

##  Objectives

* Summarize lengthy articles.
* Answer questions from article content.
* Reduce research time.
* Extract important information quickly.

##  Models Used

* **FLAN-T5 Large** – evaluated for text generation.
* **TinyLlama 1.1B** – used for summarization and question answering.

##🛠️ Technologies

* Python
* Pandas
* PyTorch
* Hugging Face Transformers
* TinyLlama
* Streamlit
* Docker
* Hugging Face Spaces

##  Workflow

```text
Article Dataset
      ↓
Text Processing
      ↓
Transformer Model
      ↓
Summarization / Q&A
      ↓
Generated Insights
      ↓
Streamlit Application
```

##  Features

*  **Article Summarization**
*  **Question Answering**
*  **Interactive Streamlit Interface**
*  **Hugging Face Deployment**

##  Dataset

The dataset contains article **titles and article text**, which are used for summarization and question answering.

##  Project Results

* Successfully generated **concise article summaries**.
* Generated **relevant answers** for questions based on article content.
* TinyLlama provided effective results for the implemented **summarization and Q&A tasks**.
* The project demonstrated the practical use of **Generative AI for automated research assistance**.

##  Future Enhancements

* Implement **RAG (Retrieval-Augmented Generation)**.
* Support multiple documents.
* Improve long-text processing.
* Enhance prompt engineering.

##  Business Impact

The system helps users **save research time, understand lengthy information quickly, and extract relevant insights** from articles.
